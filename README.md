# AI4SM Propaganda Analysis

Propaganda detection experiments on the QProp dataset, comparing classical machine learning baselines.

## Overview

This repo contains preprocessing, feature extraction, and classifier code for detecting propaganda in news text. Models explored:

- K-Nearest Neighbors (`KNN.py`, `knn_classifier.py`, `knn_final.py`)
- TF-IDF + KNN (`tfidf_knn.py`)
- Bag-of-words + Logistic Regression (`bag_of_words_preprocess_and_logistic_regression.py`)
- SVM (`svm_work_branch.py`)
